## 💻 Technologies Utilisées

### Backend
```
🟦 Laravel 10.x (PHP 8.2)
🗄️ MySQL 8.0 / MariaDB 10.11
⚡ Redis 7.0 (Cache)
🔄 Laravel Queue (Jobs asynchrones)
🔐 Laravel Sanctum (API Auth)
📧 Mailgun / SendGrid (Emails)
📱 Firebase FCM (Push Notifications)
```

### Frontend Web
```
🎨 Bootstrap 5.3 (Responsive Design)
⚡ JavaScript / jQuery 3.7
🖼️ Vue.js 3 (Composants dynamiques)
📊 Chart.js (Graphiques)
📋 DataTables (Tables interactives)
🗓️ FullCalendar (Calendrier)
```

### Applications Mobiles
```
📱 Flutter 3.16 (iOS + Android)
🎯 Dart 3.x
🔄 Provider / Riverpod (State Management)
🌐 Dio (HTTP Client)
💾 Sqflite (Local DB)
🔔 Firebase Messaging (Push)
```

### Infrastructure
```
☁️ Cloud: AWS / DigitalOcean / OVH
🌐 Web Server: Nginx 1.24
🐧 OS: Ubuntu 22.04 LTS
🔒 SSL: Let's Encrypt
🛡️ WAF: Cloudflare
📦 CI/CD: GitHub Actions
```
