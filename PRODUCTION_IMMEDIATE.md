```bash

# Voir classement

# Liste groupes d'étude

# Liste forums
curl http://localhost:8000/api/student/forums
```

### Avec Authentification (Production)

**Obtenir token:**
```bash
curl -X POST http://votre-domaine.com/api/login \
  -H "Content-Type: application/json" \
  -d '{"email": "student@example.com", "password": "password"}'
```

**Utiliser API:**
```bash
# Achievement étudiant
curl -X GET http://votre-domaine.com/api/student/achievement \
  -H "Authorization: Bearer TOKEN"

# Créer groupe d'étude
curl -X POST http://votre-domaine.com/api/student/study-groups \
  -H "Authorization: Bearer TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Groupe Mathématiques Avancées",
    "subject_id": 1,
    "privacy": "public",
    "max_members": 15
  }'
```
